The Visitor Parking Availability Map is an initial prototype of a dynamically updated campus parking tool. In lieu of a linked data pipeline to the actual hosted campus visitor parking data, a snapshot of UW-Madison visitor parking availability data has been placed into an editable Survey123 interface. In the current structure, any public user can edit the underlying data by using the embedded Editor widget.

This map has a locate function added to assist users already on campus with finding their position relative to the campus garages.
